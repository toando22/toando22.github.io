Phân tích Hành vi Khách hàng (Big Data)

Đây là dự án tốt nghiệp khóa học Big Data tại Samsung Innovation Campus (SIC). Mục tiêu là xử lý một tập dữ liệu lớn (Big Data) về giao dịch E-commerce để tìm ra các insight (thông tin chi tiết) về hành vi khách hàng và trực quan hóa kết quả trên một trang web dashboard.

Python Pandas Flask Matplotlib Big Data

Mô tả Kỹ thuật & Vai trò

Với vai trò là **Data Analyst & Python Developer**, tôi chịu trách nhiệm chính trong việc xử lý và trực quan hóa dữ liệu.

Dự án bao gồm hai phần chính: một script Python để phân tích và một ứng dụng web Flask để hiển thị.

  • Xử lý Dữ liệu (Data Processing): Sử dụng thư viện **Pandas** (Python) để đọc và làm sạch (clean) một tập dữ liệu lớn (hàng triệu dòng) từ file CSV. Thực hiện các thao tác gộp (merge), nhóm (group by), và tính toán (aggregation) để trích xuất thông tin.
  • Phân tích (Analytics): Phân tích các chỉ số quan trọng như: Tổng doanh thu theo thời gian, các sản phẩm bán chạy nhất, phân khúc khách hàng (RFM - Recency, Frequency, Monetary), và tỷ lệ mua lại.
  • Trực quan hóa (Visualization): Sử dụng thư viện **Matplotlib** và **Seaborn** để tạo ra các biểu đồ (đường, cột, tròn) mô tả các insight đã tìm được.
  • Xây dựng Web Dashboard: Xây dựng một trang web đơn giản bằng **Flask** (Python Web Framework). Sử dụng template engine (như Jinja2) và Bootstrap để tạo một dashboard hiển thị các biểu đồ và số liệu phân tích một cách trực quan, thân thiện.

Quy trình Phân tích Dữ liệu

1

Thu thập & Làm sạch Dữ liệu

Nhận dữ liệu thô (raw data). Sử dụng Pandas để kiểm tra dữ liệu thiếu (missing values), dữ liệu trùng lặp (duplicates) và xử lý chúng.

2

Phân tích Khám phá (EDA)

Thực hiện Phân tích Dữ liệu Khám phá (Exploratory Data Analysis) để hiểu rõ về tập dữ liệu, tìm ra các xu hướng ban đầu và đặt giả thuyết.

3

Trích xuất Tính năng & Trực quan hóa

Tính toán các chỉ số (KPIs) và tạo các biểu đồ (charts) bằng Matplotlib để trả lời các câu hỏi kinh doanh (ví dụ: "Khách hàng nào giá trị nhất?").

4

Xây dựng Dashboard

Xây dựng các route trong Flask, truyền dữ liệu (đã phân tích) và các hình ảnh biểu đồ sang template (Jinja2) để hiển thị trên giao diện web.
